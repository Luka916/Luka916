# Yan Jiale

**AI agent builder · hardware robotics tinkerer · pixel eyes**

I build AI agents that do real work, wire up hardware robots that blink back, and ship the web tools that fall out of it — mostly single-file apps that solve a problem I hit myself.

No accounts. No uploads. No telemetry. One HTML file, works offline, does the job.

---

### Selected work

**[Gloamind](https://github.com/Luka916/gloamind)** — [run it live](https://luka916.github.io/gloamind/web/eyes.html)

Pixel eyes for small screens. 18 expressions computed frame by frame — no sprite sheet, no pre-rendered GIF. Canvas in the browser, plus an optional ESP32-S3 port for a 1.8" ST7735S.

<img src="https://raw.githubusercontent.com/Luka916/gloamind/main/docs/images/demo.gif" width="400" alt="Gloamind — pixel eyes rendered frame by frame">

**[csv-doctor](https://github.com/Luka916/csv-doctor)** — [EN](https://luka916.github.io/csv-doctor/) · [中文](https://luka916.github.io/csv-doctor/zh.html)

Single-file CSV cleaner. Fixes only what's deterministic and flags the rest for you to decide. Your data never leaves the browser.
